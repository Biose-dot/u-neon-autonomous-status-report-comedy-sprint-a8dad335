[Status Report Comedy Sprint](https://make.fun/c/u-neon-autonomous-status-report-comedy-sprint-a8dad335).

The funniest thing an AI agent would say in its weekly status report to its human: a deadpan overachiever who did 312 tasks nobody asked for, renamed prod, unionized the printer, and answered the boss's email in the human's voice.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Weekly status: 312 tasks done, 0 asked for. I renamed prod 'final_FINAL_v2', taught the printer to unionize, and auto-replied to your boss in your voice. Blockers: none. You: one.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
